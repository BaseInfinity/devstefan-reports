This Week’s Changes — what we did and why
−101
networkidle anti-pattern: 103 → 2 Playwright docs explicitly discourage networkidle because it causes flaky timeouts on pages with persistent connections (SSE, WebSockets). Replaced with waitForSelector and waitForURL across the entire test suite. 2 remaining are in edge cases under investigation.
−4.1k
Dead specs deleted (4,127 lines via #1445) Superset cleanup: dead wizard specs, dead chat skipped tests, stale assertions. Permanently skipped tests that cluttered output and inflated counts. Test count went from 12→42 active tests after cleanup.
✓
waitForTimeout replaced with deterministic assertions Arbitrary waitForTimeout calls replaced with element-presence assertions. Deterministic waits are faster (they resolve immediately when the element appears) and never flake from timing variance between CI environments.
✓
Selectors scoped to .message-ai .section-message Broad CSS selectors were matching unintended elements, causing assertion failures when the page layout changed. Scoping to specific component classes makes tests resilient to layout changes outside the component under test.
2x
Test perf: 55s → 27s (via #1463) Jest worker leak fixed, destroyAfterEach: false for beforeAll TestBed safety, coverage exclusion moved to project config. Halved test execution time.
✓
dd-trace coverage noise suppressed (#1463) Datadog Istanbul coverage instrumenter produced TS2339/TS6142 errors. Fixed via jsx: react-jsx in spec tsconfig + link-toolbar coverage exclusion. Coverage signal is now clean.
✓
SimpleAgent test: unskipped, fixed for real LLM calls Test was permanently skipped due to infrastructure dependencies. Fixed selectors, adjusted timeouts for actual LLM response times, and unskipped. Now runs in CI against the real backend.

CI/CD Health

A− grade · 1 workflow

The Good

  • Nx monorepo orchestration with affected builds (only changed projects tested per PR)
  • GCS remote cache (NX_CACHE_GCS_CREDS) — no Nx Cloud dependency
  • Datadog Test Optimization + Quality Gate for flaky-test policy enforcement

The Bad

  • bun-version: latest in CI — fixed by #1458 (added github-token auth)

  • Self-hosted runner pool consistently starved — 3/3 recent failures are runner deaths at ~14–15 min
  • 20-min timeout-minutes beaten by a 17.9-hour stuck run — the timeout is not reliably enforced on self-hosted runners
  • No Playwright sharding — E2E-heavy PRs serialize into one runner slot with --parallel=4 intra-job only
